# Ahmed Gamal — Personal Portfolio

A terminal-inspired personal website showcasing my experience, projects, teaching, and technical skills.

**[View the live portfolio](https://ahmed-gamal24.github.io/portfolio/)**

## About

I'm a Computer Engineering student at Menoufia University and a Google Summer of Code 2025 contributor with the Debian Project. This site brings together my work in software engineering, backend development, and systems programming.

## Built with

- HTML, CSS, and vanilla JavaScript
- Google Fonts
- GitHub Pages for hosting

The site is a static website and does not require a build step or package installation.

## Run locally

Open `index.html` in a browser, or run a local server from the project folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project structure

```text
portfolio/
├── index.html             # Page content
├── css/style.css          # Styles and responsive layout
├── js/main.js             # Animations and interactions
└── assets/                # Images
```
